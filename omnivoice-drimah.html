Interface livre para o modelo OmniVoice (k2-fsa), TTS multilíngue com clonagem de voz zero-shot para 600+ idiomas. Roda de graça usando o Space público do Hugging Face — sem instalar nada. Repositório original: github.com/k2-fsa/OmniVoice

🔑 Token do Hugging Face (opcional, aumenta sua cota gratuita)

Sem token, você usa a cota compartilhada anônima (bem pequena). Colando seu token gratuito, você passa a usar sua própria cota do Hugging Face — mesmo processo, sem custo. Crie um em huggingface.co/settings/tokens (tipo "Read" já é suficiente). O token fica salvo só no seu navegador (localStorage) e é enviado direto ao Hugging Face — nunca passa por nenhum servidor meu.

Como é um Space compartilhado e gratuito, a "GPU" pode levar alguns segundos para "acordar" na primeira geração, e pode haver fila em horários de pico.
